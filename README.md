# mutipy

## 在 GitHub 网页上打开 Codespace / Open in GitHub Codespace

本仓库已配置好 GitHub Codespaces 支持，您可以直接在浏览器中运行完整的开发环境，无需在本地安装任何依赖。

**操作步骤 / Steps:**

1. 打开本仓库的 GitHub 页面（Open this repository on GitHub）
2. 点击绿色的 **Code** 按钮（Click the green **Code** button）
3. 选择 **Codespaces** 选项卡（Select the **Codespaces** tab）
4. 点击 **Create codespace on main**（Click **Create codespace on main**）

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Astro-boy-888/mutipy)

等待几秒钟，一个完整的在线开发环境（VS Code in the browser）就会在新标签页中打开，可以直接开始编码！

> A fully configured online VS Code environment will open in a new browser tab — no local setup required.
